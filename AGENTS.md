# Project Instructions

## Project Overview

This repository is a Python CLI accounting app that manages income and expenses from CSV data.

## Coding Rules

- Type hints are required for all functions and public data structures.
- A single function must be 50 lines or fewer.

## TDD Rules

- Always write the test first before implementing any behavior.
- New behavior is not complete until the test exists and passes.

## Quality Rules

- Keep cyclomatic complexity at 10 or below.

## Quality Review Rules

- Before every commit, run quality review through the `qa_engineer` subagent.

## Test Commands

- `pytest`
- `radon cc`

## Commit Rules

- When one feature is complete, commit it and push it.
